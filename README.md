# finalproject

## Comparative Analysis of Anthropometric Measurements Across Mendeley and NHANES

This repository contains the final project for **BST260 (Fall 2026)** at the Harvard T.H. Chan School of Public Health.

The project investigates anthropometric measurements using two publicly available datasets: the Mendeley Body Measurements dataset and the National Health and Nutrition Examination Survey (NHANES), August 2021–August 2023.

## Project Objectives

The main objectives of this project are:

- Explore distributions of age, height, and waist circumference.
- Examine associations between demographic characteristics and anthropometric measurements.
- Compare data quality and measurement characteristics across the two datasets.
- Identify challenges associated with integrating datasets collected from different populations and using different measurement protocols.
- Apply R programming, statistical analysis, and data visualization to generate reproducible findings.

## Datasets

**1. Mendeley Body Measurements Dataset**

Contains anthropometric measurements primarily from children and adolescents.

**2. NHANES (August 2021–August 2023)**

Contains standardized anthropometric measurements and demographic information from participants in the U.S. National Health and Nutrition Examination Survey.

## Methods

The project will use R for data cleaning, descriptive statistics, exploratory data analysis, visualization, and statistical modeling.

Two Quarto vignettes will document the analyses, findings, and limitations of each dataset.
